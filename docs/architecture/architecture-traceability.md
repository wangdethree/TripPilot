# 架构追踪矩阵

> 状态：Accepted
>
> 基线：v1.0

本矩阵证明架构设计来自已经批准的需求，而不是为了使用技术而增加技术。

| 架构驱动因素 | 主要需求 | 设计响应 | ADR | 验证 |
| --- | --- | --- | --- | --- |
| `AD-001` 受控长任务 | `FR-014`、`FR-017`～`FR-019` | 显式状态图、持久化任务、中断、取消和终态 | `ADR-0003`、`ADR-0004`、`ADR-0007` | 状态、取消、恢复和端到端测试 |
| `AD-002` 确定性边界 | `FR-011`、`BR-003`～`BR-005` | 独立领域模块，Agent 只生成候选 | `ADR-0002`、`ADR-0003` | 领域单元、属性与硬门禁 |
| `AD-003` 结构化数据 | `FR-001`、`FR-007`、`NFR-MAINT-001` | Pydantic、Structured Outputs、本地二次校验 | `ADR-0006` | Schema 与无效输出测试 |
| `AD-004` 可替换工具 | `FR-012`、`FR-015` | 端口、模拟与真实适配器、契约测试 | `ADR-0001`、`ADR-0002` | 工具契约与集成测试 |
| `AD-005` 外部不可靠 | `FR-015`、`NFR-REL-*` | 超时、有限重试、缓存、错误分类与降级 | `ADR-0001`、`ADR-0003` | 故障注入与时效测试 |
| `AD-006` 版本一致性 | `FR-013`、`FR-016`、`FR-022`～`FR-024` | PostgreSQL 事务、不可变版本、`If-Match` | `ADR-0005`、`ADR-0007` | 原子写入、并发冲突和回滚 |
| `AD-007` 安全边界 | `NFR-SEC-*` | 令牌摘要、工具允许列表、出站控制、脱敏 | `ADR-0001`、`ADR-0006` | 注入、SSRF、Secret 与越权测试 |
| `AD-008` 匿名隐私 | `NFR-PRIV-*` | 最小存储、短期原文、保留与级联删除 | `ADR-0005`、`ADR-0007` | 过期、删除、日志和枚举测试 |
| `AD-009` 可观测复现 | `NFR-OBS-*`、评测需求 | OTel、版本化 Prompt、数据集与报告 | `ADR-0003`、`ADR-0006` | Trace 契约和评测复现 |
| `AD-010` 性能与异步 | `NFR-PERF-*` | I/O 异步、持久化执行器、租约和并发限制 | `ADR-0004`、`ADR-0005`、`ADR-0007` | 延迟、10 并发和取消测试 |
| `AD-011` 资源预算 | `NFR-COST-*` | `ExecutionBudget`、调用预留和用量表 | `ADR-0003`、`ADR-0006` | Token、工具和超时上限 |
| `AD-012` 可维护性 | `NFR-MAINT-*` | 模块化单体、依赖规则、锁文件和 CI | `ADR-0002`、`ADR-0004`、`ADR-0005` | 架构检查、CI 与部署演练 |

## 变更影响

以下变更必须重新检查追踪关系：

- 新增或删除业务状态与工作流节点
- 改变硬性约束最终判定位置
- 更换 Agent 运行时、数据库或模型 API
- 将 API 与 Worker 拆分为独立服务
- 新增外部写工具、支付或预订能力
- 改变匿名令牌或数据保留语义
- 修改性能、成本或评测门禁
