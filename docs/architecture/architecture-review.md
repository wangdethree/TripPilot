# 架构评审清单

> 状态：In Review
>
> 候选基线：v1.0

## 需求与范围

- [x] 架构驱动因素可追踪到批准需求
- [x] 单城市 1～3 日、单 Agent 和无外部写操作边界未被扩大
- [x] 架构没有把 Should 或 Could 功能错误提升为 MVP 必需依赖
- [x] 模块化单体符合当前团队与并发规模

## 系统与模块

- [x] 用户、TripPilot 和外部系统边界明确
- [x] API、应用、执行、Agent、领域、端口和基础设施职责明确
- [x] 领域模块不依赖框架、模型、数据库或供应商
- [x] 模块依赖方向和禁止行为已定义
- [x] 数据所有权和权威存储已定义

## Agent

- [x] 使用显式有限状态图，不存在无界模型或工具循环
- [x] 用户确认、重规划上限和终态规则已表达
- [x] 模型、工具和确定性规则职责已分离
- [x] Checkpoint、恢复、幂等和取消传播已定义
- [x] 异步与顺序执行边界已定义
- [x] 模型和工具资源预算已定义

## 数据与接口

- [x] 任务、行程版本、资源用量、缓存和调用元数据已设计
- [x] 不可变版本、原子提交和乐观并发已定义
- [x] 关系字段与 JSONB 使用边界已定义
- [x] 匿名令牌、幂等键、ETag 和稳定错误已定义
- [x] 长任务 API 不依赖单个长连接
- [x] 数据保留、删除和迁移策略已定义

## 安全与隐私

- [x] 用户、模型和工具输入均被视为不可信
- [x] Prompt 注入、SSRF、工具越权和令牌泄露具有控制
- [x] 密钥、日志、Trace 和评测数据边界已定义
- [x] 限流、资源耗尽和供应链风险具有验证方式
- [x] 第一版没有引入支付、预订或任意外部写权限

## 质量与运行

- [x] 技术选择具有官方资料和需求依据
- [x] Fake 与真实适配器策略支持离线测试
- [x] 评测数据、Prompt、模型、工具和报告可以版本关联
- [x] Trace、Metric 和 JSON 日志职责明确
- [x] 本地、CI、集成和演示环境已定义
- [x] 数据库迁移、健康检查、备份和发布流程已定义
- [x] 关键架构风险具有测试或重新评估条件
