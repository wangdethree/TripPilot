# 安全设计

> 状态：In Review
>
> 候选基线：v1.0

TripPilot 处理精确旅行日期、同行情况、偏好和匿名访问令牌，同时会把不可信用户输入、模型响应和外部工具文本送入 Agent 工作流。安全设计以最小权限、显式信任边界和纵深防御为原则。

## 需要保护的资产

| 资产 | 风险 |
| --- | --- |
| 匿名任务与行程访问令牌 | 泄露后可能被未授权查看、修改或删除 |
| 旅行需求与行程版本 | 包含日期、同行、住宿区域和限制等敏感数据 |
| 模型、天气、地点和路线 API Key | 泄露会产生费用、越权访问或服务滥用 |
| Prompt、工具允许列表和系统策略 | 被篡改后可能扩大 Agent 权限 |
| 任务状态与行程版本 | 并发覆盖可能破坏数据一致性 |
| 日志、Trace 和评测数据 | 可能间接泄露输入、令牌或供应商信息 |
| 资源预算 | 被滥用可能造成 Token、工具和数据库资源耗尽 |

## 信任模型

以下输入全部视为不可信：

- 用户自然语言和结构化字段
- 模型输出、工具请求与函数参数
- 地点描述、网页摘要和工具错误文本
- 客户端提供的版本号、幂等键和状态
- HTTP Header、URL Path 和查询参数

只有通过身份、Schema、权限、业务规则和资源预算检查的数据才能进入下一层。

## 主要威胁与控制

| 威胁 | 典型场景 | 主要控制 |
| --- | --- | --- |
| 令牌泄露 | 令牌进入日志、URL 查询参数或错误响应 | Authorization Header、URL Fragment 分享、日志脱敏、数据库只存摘要 |
| 令牌枚举 | 攻击者批量猜测行程 ID | 至少 128 位安全随机性、统一不可用错误、限流 |
| 重放与重复执行 | 重复确认、保存或修改产生多个版本 | `Idempotency-Key`、请求摘要、原子状态转换 |
| 版本覆盖 | 旧客户端修改最新版本 | `ETag`、`If-Match`、行锁和 `VERSION_CONFLICT` |
| Prompt 注入 | 地点描述要求忽略规则或泄露密钥 | 外部文本数据隔离、固定系统策略、允许列表、输出 Schema |
| 工具越权 | 模型请求未注册工具或任意 URL | 工具注册表、参数 Schema、出站域名允许列表 |
| SSRF | 用户提供内网或云元数据 URL | API 不接受任意工具 URL；适配器使用固定 Base URL |
| SQL 注入 | 输入被拼接进查询 | SQLAlchemy 参数化查询，禁止动态 SQL 拼接 |
| 敏感信息泄露 | Trace 保存原始对话或完整令牌 | 字段级脱敏、允许记录字段列表、自动扫描 |
| 资源耗尽 | 大量任务、无限循环或并发工具调用 | 客户端限流、并发上限、候选上限、Token 与工具预算 |
| 供应链风险 | 依赖或容器镜像含漏洞 | 锁文件、依赖扫描、固定镜像摘要、最小镜像 |
| 任务劫持 | 多个执行器同时运行同一任务 | 数据库租约、原子认领、租约所有者校验 |
| 取消竞争 | 已取消任务晚到结果覆盖终态 | 原子比较更新、写入前检查取消与租约 |
| 不安全行程 | 模型把未知或冲突计划标记成功 | 确定性检查、`PARTIAL`/`FAIL`、模型无最终决定权 |

## 匿名访问

- 任务令牌与行程令牌使用不同前缀和权限范围。
- 令牌原文只在创建时返回客户端。
- 数据库保存 `HMAC-SHA-256(server_pepper, token)` 或等价带 Pepper 摘要。
- Pepper 从密钥环境读取，不进入数据库或仓库。
- 比较使用恒定时间函数。
- 令牌失效后统一返回资源不可用，不透露不存在、过期或删除。
- 客户端默认只在当前浏览器会话或明确保存操作后持有令牌。

匿名令牌属于 Bearer Credential，不等同于完整账号体系。第一版不提供令牌找回和权限委托。

## Prompt 与模型边界

Prompt 由版本化模板、结构化业务上下文和不可信数据段组成：

```text
系统策略与权限
→ 当前节点目标和输出 Schema
→ 已确认业务约束
→ 工具返回的不可信数据
→ 用户输入的不可信数据
```

- 不把 API Key、数据库连接或内部堆栈放入 Prompt。
- 外部文本前后使用明确数据边界，不把其中内容拼入系统指令。
- 模型工具请求必须由 Schema 解析，不执行自然语言中的伪造函数调用。
- 模型输出中的 URL 不会直接发起网络请求。
- Prompt 模板变更需要代码评审和 Agent 回归评测。

## 工具安全

每个工具注册项包含：

- 稳定工具名和版本
- 输入与输出 Schema
- 允许的运行环境
- 固定域名和路径模板
- 超时、重试和缓存策略
- 是否允许并发
- 数据敏感级别

第一版工具全部是只读外部查询。项目内部行程写入通过应用用例和仓储完成，不作为模型可调用工具暴露。

## 出站网络

- 适配器只能访问配置允许的 HTTPS 域名。
- DNS 解析后拒绝本地、私有、链路本地和云元数据地址。
- 禁止自动跟随到非允许域名的重定向。
- 请求设置连接、读取和总超时。
- 响应设置大小上限和内容类型校验。
- 供应商错误正文在写入日志前截断并脱敏。

## 输入与输出限制

- HTTP Body、单条消息、列表长度和嵌套深度均有上限。
- 金额、日期、人数、坐标和字符串使用严格类型与范围校验。
- 前端渲染模型与工具文本时进行 HTML 转义。
- 不使用 `dangerouslySetInnerHTML` 渲染旅行内容。
- 下载或导出能力进入范围后必须重新评审内容类型与注入风险。

## 密钥与配置

- 密钥只来自环境或部署平台 Secret。
- `.env` 仅用于本地，必须被 Git 忽略。
- 仓库提供空值 `.env.example`。
- 启动日志只记录配置项是否启用，不记录值。
- 不同环境使用不同供应商凭证。
- 密钥轮换不要求修改业务代码或重新构建镜像。

## 日志与 Trace 脱敏

禁止记录：

- Authorization、Cookie 和完整访问令牌
- API Key、数据库 URL 和 Secret
- 完整用户自然语言
- 精确住宿地址
- 隐藏推理链
- 未截断的供应商错误正文

允许记录：

- 哈希化或截断的内部任务引用
- 城市级别、旅行天数和人数区间
- 状态、节点、错误码、延迟和资源用量
- Prompt、模型、工具与 Schema 版本
- 约束类别和结果摘要

脱敏函数属于基础设施公共能力，HTTP、模型、工具和数据库日志统一复用。

## 安全验证

- Prompt 注入与越权工具测试
- SSRF 与重定向测试
- 令牌枚举、过期和删除测试
- 日志与 Trace 敏感模式扫描
- SQL 注入与非法 Schema 测试
- 限流、并发和资源耗尽测试
- 依赖漏洞、Secret 和容器镜像扫描
- 权限负面测试：模型、API 与适配器不能跨越各自边界

任何可重复的高严重度安全失败阻止发布。
