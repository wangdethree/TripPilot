# ADR-0001：使用可替换的外部工具适配器

> 状态：Accepted
>
> 日期：2026-07-28

## 背景

TripPilot 需要获取天气、地点、路线和费用等信息。自动测试如果直接依赖真实外部服务，会受到数据变化、网络、限流和费用影响；如果只使用模拟数据，最终产品又无法证明真实工具集成和异常处理能力。

## 决策

系统为天气、地点、路线等外部能力定义稳定的工具接口，并分别提供模拟实现和真实实现。

- 开发、单元测试和 Agent 回归评测默认使用固定模拟数据。
- 集成测试和演示环境使用真实外部服务。
- 最终演示版本至少接入真实天气和路线或地点服务。
- Agent 只依赖工具接口，不直接依赖具体服务商。
- 真实工具必须提供参数校验、超时、有限重试、缓存、结构化错误、来源和查询时间。
- 服务失败时优先读取有效缓存；无法降级时返回明确的未知或失败状态。
- 模型不得生成虚构数据代替失败的工具结果。

## 备选方案

### 所有环境都调用真实服务

实现直观，但测试结果不稳定，难以复现异常场景，还会受到网络、限流和费用影响。

### 只使用本地模拟数据

开发简单且测试稳定，但无法体现真实数据集成、故障处理和多城市扩展能力。

## 影响与后果

正面影响：

- 自动测试具有确定性和可重复性。
- 可以稳定构造雨天、超时、限流和无结果等异常场景。
- 更换外部服务商时不影响 Agent 和核心业务逻辑。
- 演示版本仍能提供真实数据能力。

需要承担的成本：

- 每类工具需要维护接口、模拟实现和真实实现。
- 需要增加契约测试，保证不同实现返回一致的数据结构。
- 需要明确管理缓存时效和不同环境的配置。
