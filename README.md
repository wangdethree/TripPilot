# TripPilot

TripPilot 是一个面向国内城市自由行场景的旅行规划 Agent。项目将按照接近企业实践的软件开发流程推进，重点覆盖需求分析、架构设计、工具调用、状态管理、Agent 评测、测试、部署与可观测性。

## 当前状态

- 阶段：Sprint 0（产品立项与需求分析）
- 状态：初始化
- 第一版目标：为国内城市 1～3 日自由行生成可检查、可调整的个性化行程

## 初步范围

- 接收城市、日期、人数、预算、兴趣偏好和旅行节奏
- 查询或读取景点、天气、路线和费用信息
- 生成多日旅行计划
- 检查预算、时间、距离和天气等约束
- 根据用户反馈局部调整行程

## 暂不包含

- 真实机票、酒店或门票交易
- 自动支付
- 无人工确认的高风险外部操作
